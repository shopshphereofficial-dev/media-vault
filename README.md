# MediaVault

MediaVault is an original, privacy-first, ad-free Android media downloader, player, and encrypted vault built with Kotlin, Jetpack Compose, and Material 3.

## Features
- **Built-in Browser:** Fast web browsing with direct downloadable media sniffing.
- **Background Downloader:** Resumable, concurrent downloads with speed, ETA, pause/resume, and notification progress.
- **Media Player:** Integrated Android Media3 (ExoPlayer) with Picture-in-Picture (PiP) and background playback.
- **Media Library:** Filter by Videos, Audio, Images, and Documents. Full search, favorites, file sharing, and deletion.
- **Private Vault:** Hardware-backed biometric / PIN authentication and AES-GCM file encryption.
- **Official Account Data Import:** Safely import exported data ZIP archives with protection against Zip Slip path traversal.
- **Privacy & Security:** Zero ads, zero trackers, zero analytics, strictly respects scoped storage and direct media streams.
